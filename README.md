# face_orient_fixer

SketchUpでモデリングしたオブジェクトの**面の表裏（反転）を一瞬で外側（表面）に統一する**、3Dプリント用途に特化した軽量プラグインです。

3Dプリンター用のSTLデータを出力する際、SketchUpの仕様で一部の面が裏返ってしまい、スライサー（Curaなど）で「開いているはずの穴が肉で埋まる」「ソリッドエラーが起きる」といった現象をボタン一発で解決します。

SketchUpの内部API（`orient_faces`）が未実装である**Google SketchUp 8（内部Ruby 1.8環境）でも確実に動作するよう、独自の巡回反転アルゴリズム（BFS）で設計されています。**

---

## 🚀 特徴

* **完全自動の地続き解析**: 基準となる面から隣接する面へと数珠つなぎにプログラムが走査し、向きが狂っている面だけをピンポイントで強制反転（`reverse!`）させます。
* **SketchUp 8対応**: 古いバージョンのSketchUpや、UIの状態（フォーカス）に依存せず、ピュアなRubyコードのみで確実に面をひっくり返します。
* **ワンクリックで元戻り**: 万が一意図しない方向に揃った場合も、`Ctrl + Z`（取り消し）1回で実行前の状態に安全に戻せます。

---

## 🛠 動作確認環境

* Google SketchUp 8 (Ruby 1.8.6 環境)
* Windows / Mac

---

## 📦 インストール方法

1. 本リポジトリの `face_orient_fixer.rb` をダウンロードします。
2. SketchUpの `Plugins` フォルダにファイルを配置します。
   * **Windows**: `C:\Program Files (x86)\Google\Google SketchUp 8\Plugins`
   * **Mac**: `/Library/Application Support/Google SketchUp 8/SketchUp/Plugins`
3. SketchUpを再起動（または起動）します。

---

## ⌨️ おすすめの割り当て設定（ショートカット）

3Dプリント用に出力する前の「最終チェックコマンド」としてショートカットに登録すると非常に快適です。

1. メニューから **「ウィンドウ」 > 「環境設定」** を開きます。
2. 左メニューの **「ショートカット」** を選択します。
3. 検索欄に `Fix All Front Faces` と入力します。
4. 機能一覧から `プラグイン/Fix All Front Faces` を選択します。
5. 「ショートカットを追加」の欄にお好みのキー（例: `Ctrl + Shift + F` や `F5` など）を入力し、**「＋」ボタン** を押して確定します。

---

## 📖 使い方

1. 面の向きがバラバラ（白と青灰色が混在）になっているパーツをダブルクリックし、**「グループまたはコンポーネントの編集モード（中に入った状態）」**にします。
2. 上部メニューの **「プラグイン」 ＞ 「Fix All Front Faces」** を実行します（または登録したショートカットキーを押します）。
3. 接続されているすべての面の向きが自動で綺麗に統一されます。
4. そのままいつも通りSTL形式で書き出し、スライサーに読み込ませてください。

※完全に孤立してどこにも接触していない面がある場合は処理をスキップするため、地続きの美しいモデリング構造のパーツに対して最も効果を発揮します。
